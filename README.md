## Base de Datos

**Crear la base de datos:**

1. Abrir el gestor de base de datos (XAMPP/phpMyAdmin).
2. Ejecutar el archivo `alquileres_temporarios.sql` provisto en el repositorio.
3. Verificar que se haya creado la base de datos y sus tablas correspondientes.
4. Configurar la cadena de conexión del proyecto en el archivo `appsettings.json`.

---

## Ejecución

1. Clonar el repositorio.
2. Abrir la solución en Visual Studio.
3. Restaurar las dependencias.
4. Configurar la conexión a la base de datos local.
5. Ejecutar el proyecto.
